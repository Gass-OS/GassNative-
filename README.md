## About

GassNative is an experimental Android application that brings a Debian Linux userspace and XFCE desktop to compatible ARM64 Android devices. It uses PRoot to run Linux userspace without requiring Android root access.

## What's new in v0.7 — Build 13

- Refreshed application interface and Linux distribution icons
- GassNative AI assistant with offline help guides
- Linux distribution selection
- Windows VM and Windows games entry points
- Music and radio improvements
- Desktop and settings updates
- Updated release metadata and version checking

Read the [v0.7 release notes](https://github.com/Gass-OS/GassNative-/releases/tag/gassnative-v0.7-build13).

## Features

- Debian 13 Trixie for ARM64 devices
- XFCE graphical desktop
- Dedicated native Android application
- Configurable DNS, profiles, bind mounts and environment variables
- AI assistant and built-in help content
- Music and radio features
- Windows VM and games entry points
- Ongoing work on desktop integration and GPU acceleration

## Installation

1. Download [gassnative.apk — v0.7 Build 13](https://github.com/Gass-OS/GassNative-/releases/download/gassnative-v0.7-build13/gassnative.apk).
2. Allow installation from your browser or file manager if Android asks.
3. Install and open GassNative.
4. Follow the in-app instructions to install Debian, then launch the desktop.

An internet connection and sufficient free storage are required for the initial Linux installation.

**Compatibility:** Android 7.0+ (API 24+) and ARM64 (`arm64-v8a`).

## Technology

- **Distribution:** Debian 13 Trixie
- **Architecture:** ARM64 (`arm64-v8a`)
- **Desktop:** XFCE
- **Linux userspace:** PRoot
- **Application:** Native Android Java app
- **Build system:** Android SDK tools and custom scripts

## Graphics acceleration

Hardware acceleration is experimental and is not guaranteed on every device. GPU support depends on the device, drivers and configuration. Some applications may use software rendering.
