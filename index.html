Meet the project

What is GassNative?

GassNative v0.4 — Build 10 brings a refreshed Android interface with dedicated Radio, TV and Games screens, alongside desktop improvements. The app manages a Debian ARM64 userspace, while PRoot provides a rootless way to run Linux userspace tools.

📱

Built for Android

Install the APK, configure your Linux environment, and manage profiles and settings from a dedicated Android interface.

🐧

A Debian Linux userspace

Use Debian ARM64 packages and an XFCE desktop session. App compatibility and performance depend on the package and device.

Features

Your Linux environment.
Your way.

Explore the desktop, tools and possibilities of Linux on mobile hardware—with clear notes about what is experimental.

◈

Debian ARM64

A Debian 13 Trixie ARM64 userspace for compatible 64-bit Android devices.

▦

XFCE desktop

A lightweight desktop with familiar panels, windows and applications.

⌘

PRoot environment

Runs Linux userspace through PRoot without requiring Android root access; it is not a full virtual machine.

▣

Native Android app

Manage installation, profiles, DNS, bind mounts and environment settings from the Android interface.

◉

Display research

Ongoing exploration of Wayland, Xwayland and integrated display rendering.

⌁

Graphics exploration

GPU acceleration is experimental; not every app or device is guaranteed to use hardware rendering.

📻

Radio

A dedicated radio screen for supported internet radio streams.

📺

TV

A dedicated TV screen for compatible video streams and playlists.

🎮

Games

A dedicated games hub for supported games and launch options.
